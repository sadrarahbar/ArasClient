# Tesla Vpn برای لینوکس

پنجرهٔ اصلی ۳۲۰×۶۰۰ است و چیدمان فشرده و عمودی دارد؛ دکمهٔ مرکزی اتصال ۱۲۸×۱۲۸ است.
پس‌زمینه `#0F1626` و لوگوها از فایل‌های ارائه‌شدهٔ کاربر هستند.

## اجرا و نصب

بستهٔ `TeslaVpn-1.0.0-linux-x86_64.tar.gz` را استخراج کنید و فایل `TeslaVpn` را
اجرا کنید. پوشهٔ `_internal` باید کنار فایل اجرایی بماند. نیازی به نصب Python
یا Qt برای اجرای بسته نیست. برای افزودن به منوی برنامه‌ها، `./install.sh` را
از داخل پوشهٔ استخراج‌شده اجرا کنید. نصب در پوشهٔ شخصی کاربر انجام می‌شود.

این خروجی روی Ubuntu 26.04 x86_64 ساخته شده است. سازگاری باینری با توزیع‌های
قدیمی‌تر تأیید نشده؛ برای آن‌ها می‌توان از سورس همان توزیع خروجی ساخت.

## اتصال

- **System VPN / TUN** پیش‌فرض است. برای عبور ترافیک کل سیستم، به `pkexec`،
  `iproute2`، `nftables` و `/dev/net/tun` نیاز دارد و هنگام اتصال پنجرهٔ تأیید
  مدیر سیستم باز می‌شود. هسته‌های کانفیگ با شناسهٔ کاربر اجرا می‌شوند؛ فقط
  بخش مسیریابی شبکه دسترسی مدیر دارد. درخواست مدیر را فقط خودتان تأیید کنید.
- **System proxy** بدون دسترسی مدیر روی KDE و GNOME پشتیبانی می‌شود. فقط
  برنامه‌هایی که تنظیمات پراکسی دسکتاپ را رعایت کنند از آن استفاده می‌کنند.
  روی KDE، تنظیمات GSettings برنامه‌های GTK مانند Firefox نیز هماهنگ و هنگام
  قطع اتصال، همراه تنظیمات KDE به حالت قبلی بازگردانده می‌شوند. مرورگر باید
  روی «Use system proxy settings» باشد؛ تنظیمات مستقل مرورگر بازنویسی نمی‌شوند.
- وضعیت سبز پس از موفقیت درخواست HTTPS نمایش داده می‌شود. در TUN، پس از
  فعال‌شدن رابط شبکه، درخواست HTTPS مستقیم نیز آزمایش می‌شود.
- برای قطع یا لغو اتصال، دوباره دکمهٔ مرکزی را بزنید. بستن پنجره اتصال را قطع
  می‌کند. مسیرها و تنظیمات پراکسی قبلی هنگام قطع بازگردانده می‌شوند.
- Qt فقط SOCKS تأییدشده را آزمایش می‌کند؛ TCP ping یا صرف بازبودن پورت مبنای
  نمایش موفقیت نیست.

## کانفیگ

همیشه فقط یک کانفیگ ذخیره می‌شود؛ ورودی چندکانفیگی اولین مورد معتبر را نگه
می‌دارد. واردکردن متن نامعتبر، کانفیگ قبلی را حذف نمی‌کند.

سه روش ورود: QR (تصویر یا دوربین)، کلیپ‌بورد و فایل محلی.
دوربین اختیاری است و برای آن `ffmpeg` و دسترسی به دستگاه `/dev/video*` لازم است.

قالب‌های پشتیبانی‌شده:

- خروجی **Export to Nekoray** نسخهٔ اندروید برای WG/MASQUE با سایفون اختیاری؛
  برای نگه‌داشتن هویت و پارامترهای دقیق اتصال، این روش پیشنهاد می‌شود.
- لینک `aether://` برای WG/MASQUE تک‌مرحله‌ای با سایفون اختیاری؛ هویت مستقل
  روی لینوکس ساخته می‌شود. پارامترهای اختصاصی یا اثرانگشت سفارشی را با خروجی
  Nekoray کامل وارد کنید.
- JSON کامل Xray، لینک‌های VLESS/VMess/Trojan/Shadowsocks/SOCKS و فایل WireGuard.
- فایل رمزدار `.arasc`، Tor و تونل‌های چندمرحله‌ای در این نسخه پشتیبانی نمی‌شوند.

فایل کانفیگ شامل اطلاعات محرمانه است و در `~/.config/tesla-vpn/` با مجوز خصوصی
نگهداری می‌شود. هویت‌های بازسازی‌شده در اجراهای بعدی بازنویسی نمی‌شوند.

## توسعه

```bash
./linux/setup.sh
./linux/run.sh
QT_QPA_PLATFORM=offscreen linux/.venv/bin/python -m unittest discover -s linux/tests -v
./linux/build.sh
```

ساخت به Python 3.11+، PyQt6 و binutils نیاز دارد. اسکریپت آماده‌سازی فقط
باینری‌های رسمیِ نسخه‌های مشخص را می‌گیرد و SHA-256 هر منبع را کنترل می‌کند.
سورس اندروید و خروجی‌های APK در این برنچ تغییر نمی‌کنند.
