# اشتراک Aether با Nekoray در لینوکس

در ArasClient، منوی Share پروفایل Aether را باز کنید، **Export to Nekoray** را بزنید
و سپس **کپی لینک Nekoray** را انتخاب کنید. خروجی `nekoray://custom#…` است.

این خروجی تونل Aether را با هویت WARP ذخیره‌شده، تنظیمات پروتکل، اسکن، TLS و
سایفون به لینوکس منتقل می‌کند. اتصال روی لینوکس مستقل از روشن‌بودن گوشی است.
این کار تبدیل MASQUE به VMess/VLESS نیست: Nekoray 4.0.1 با sing-box 1.9.7
تونل را از طریق قابلیت Custom External Core و هستهٔ Aether اجرا می‌کند.

## آماده‌سازی یک‌بارهٔ لینوکس

از پوشهٔ اصلی پروژه اجرا کنید (Python 3.11 یا جدیدتر):

```bash
python3 tools/nekoray/install.py
```

این نصب به sudo نیاز ندارد. نسخهٔ ثابت Aether 2.4.0 و برنامهٔ سایفون همراه آن
از انتشار رسمی دریافت می‌شوند و SHA-256 آرشیو پیش از نصب بررسی می‌شود.

در تنظیمات Nekoray، بخش **Basic Settings → Core → Extra Core**، این مورد را اضافه کنید:

- Name: `aras-aether`
- Path: مسیر چاپ‌شده توسط نصب‌کننده، معمولاً
  `/home/USERNAME/.local/share/aras-nekoray/aras-aether`

حالا لینک کپی‌شده را با **Import from clipboard** یا `Ctrl+V` وارد Nekoray کنید.
پروفایل را اجرا و برای آزمایش اولیه System Proxy را روشن کنید. مسیر TUN و
جلوگیری از برگشت ترافیک هستهٔ خارجی به داخل TUN در این تغییر آزموده نشده است.

## محدودهٔ پشتیبانی

- پروتکل‌های Aether: `wg` و `masque`، شامل HTTP/2 و HTTP/3.
- سایفون داخل تونل یا اطراف آن، همراه با تنظیم کشور خروجی و حالت اتصال.
- هویت WARP باید قبلاً با اتصال موفق در گوشی ایجاد شده باشد.
- تور، تونل دو مرحله‌ای، فرمان خام و زنجیرهٔ پروفایل‌ها فعلاً خروجی ندارند؛
  برنامه به‌جای حذف خاموش این تنظیمات، پیام عدم پشتیبانی می‌دهد.
- پروفایل‌های محافظت‌شده قابل خروجی گرفتن نیستند.

لینک شامل کلیدهای اتصال است؛ آن را فقط با کسی که باید امکان اتصال داشته باشد
به اشتراک بگذارید. ابزار لینوکس اطلاعات هویت را با مجوز `0600` نگه می‌دارد و
تمدیدهای بعدی هسته را با کلیدهای قدیمی خروجی بازنویسی نمی‌کند.
